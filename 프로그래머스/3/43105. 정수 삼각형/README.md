# [level 3] 정수 삼각형 - 43105 

[문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/43105?language=python3) 

# 분석
- 유형: DP
- 핵심 아이디어: Bottom-up DP
- 시간 복잡도: O(n²)
- 공간 복잡도: O(1)

---

## 문제 핵심

삼각형의 꼭대기에서 바닥까지 이동할 때,
매 단계에서 왼쪽 아래 또는 오른쪽 아래로 이동하며 얻을 수 있는
경로 합의 최댓값을 구한다.

## 접근 과정

처음에는 위에서 아래로 완전 탐색하는 방식으로 풀었으나 오버헤드가 과했다.
매번 분기되는 경로를 일일히 탐색하며 동일 계산이 반복됐다.

바닥에서부터 각 위치까지의 최댓값을 미리 계산해 저장하면, 위 칸은 아래의 두 후보 중 더 큰 값만 선택하면 된다.

## 풀이 이후 리팩토링

tmp 배열을 만들지 않고 입력 배열을 DP 테이블로 재활용함으로써 메모리 사용을 줄였다.

## 배운 점 및 느낀 점

처음으로 Level 3 문제를 해결하며, 알고리즘 지식이 실제 문제 해결 속도와 방향을 바꾼다는 점을 체감했다.
